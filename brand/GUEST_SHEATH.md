# Guest Sheath — this repo only

Public rule for HASEOS sheathed guests. The roster of cards is ONE-guest-cards, not this file.

Third-party personas enter this product only as sheathed guests.

- A guest has a display name, a vendor, and a role on this page.
- Skills may appear as HITL-selectable cards.
- Selecting a card is not identity fusion.
- Selecting a card is not promotion.
- The product remains the product. The guest remains a guest.

Allowed backends (product features, not a shared nervous system):

- Puter.js (user-pays, client-side)
- OpenRouter BYOK (key on device or this repo’s host secrets)
- Google AI Studio
- NVIDIA Build

Keys live only in this repo’s `.env` / host secrets, or on the user’s device. Never paste keys into chat.

Customer UI words: **sheathed guest**, **named helper**.

Do not print Senior Sovereign, infant, or other-workshop rank titles on customer surfaces.
