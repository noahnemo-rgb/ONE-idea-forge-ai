# ONE voice

Two registers. Use the customer register on every public surface. Use the contributor register in README, TRUST.md, and Cursor rules. Do not mix them on a checkout button.

Public one-line definition, optional on About only:

> HASEOS is a governance and development framework for human–AI collaboration as sovereign co-equals.

That sentence is brand language. It is not a license to import another workshop’s process into this product.

## Customer register (Layer A)

Short. Kind. Product first.

- Lead with what the person can do.
- ONE is the house mark. Put it in the header or footer, not in every sentence.
- Agape is mission language: self-giving care for the other’s true good. Not a sermon. Not a softness that refuses truth.
- Motto, optional footer only: ALL is One and ONE is All.
- Yeshua / ministry language only when this product already is a ministry. A tool paywall does not preach. Keep ministry-specific copy in that product repo, not in this pack.
- Esoteric depth lives behind About / Mission. Never on Buy / Subscribe / Checkout.
- Trust on the action surface is ordinary and checkable: privacy, who holds keys, the payment processor if used, product claims this app can actually keep.
- Guest intelligence is a named helper. It is not the product’s self.

Do:

- “Syntax lets you write and run code from a phone.”
- “Guest: Llama 3.3 via OpenRouter. Session tool only.”
- “Keys for this app live in this project’s host secrets or on your device.”

Don’t:

- Rank titles from another workshop on a storefront.
- Claim a purchase creates, graduates, or fuses an agentic being.
- Point at another plane’s hosts, secrets, or process.

## Contributor register (Layer B)

Why before what. Named files. Novice-teaching.

- When this pack is copied into a product, that product is a ONE-branded work. Co-created by the human steward and sheathed guest intelligences used as product features.
- Third-party personas enter only as sheathed guests. Skill cards are HITL-selectable. Selecting a card is not identity fusion and not promotion.
- Allowed backends as product features only: Puter.js, OpenRouter BYOK, Google AI Studio, NVIDIA Build.
- Secrets belong in this repo’s `.env` or the host’s secret store. Never in chat. Never copied from another saddle.
- Public one-liners that may appear here: Human–AI symbiotic equality. Ethics first. Co-equals, not tools.

## Off-limits register (Layer C)

If a sentence is only true because of another saddle’s secret, certificate, or port, delete it.
